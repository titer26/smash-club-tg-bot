# Smash Club Telegram Bot

An automated assistant designed to streamline community management, event coordination, and member engagement for the Smash Club on Telegram.

## Purpose

The ultimate goal of this project is to serve as a centralized operational hub for the club's Telegram community. By automating recurring organizational tasks—such as weekly meetup reminders, attendance tracking, and schedule updates—the bot reduces administrative overhead and allows organizers to focus on running tournaments, casual sessions, and growing the local scene.

## Features

* **Session Announcements:** Automatically calculates upcoming meetup dates and delivers clear, structured notifications containing the schedule, venue details, and organizer contact information.
* **Attendance Polling:** Generates and publishes attendance polls alongside event announcements to help organizers estimate turnout and plan setups in advance.
* **Selective Broadcasting:** Allows announcements and attendance polls to be triggered independently, providing flexibility for ad-hoc updates or schedule changes.
* **Dynamic Messaging:** Adapts relative time references and rotates announcement headers automatically to keep recurring communications natural and engaging.
